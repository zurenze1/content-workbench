# 内容创作工作台 · P1 / 0.1.0

以可追溯资料为基础的本地创作工作台。真实采集、完整原文件、具体证据、选题和脚本共用一份服务端数据库。当前交付P1，热点自动化、模型、平台接口和复盘尚未启用。

## 三分钟开始

需要 Node.js **24.21.0**（24.x）和 npm。首次在仓库目录执行：

```sh
npm ci --ignore-scripts
npm run build
npm start
```

在浏览器打开 **http://127.0.0.1:4781/**。Mac也可双击仓库里的 `启动工作台.command`；运行期间保留终端，退出终端或结束进程会停止本地服务。默认仅监听本机，不向公网开放。

1. 在“账号与备份”建立自己的账号或对标档案；角色标注不代表获得平台运营权限。
2. 创建选题，填写核心问题和角度。
3. 点“采集资料”，粘贴公开网址/分享文案、原文，或上传文件。链接逐项显示队列与实际结果，重复网址不重复创建资料。
4. 在资料详情核对来源、四个分类维度、许可证据和备注。无法取得正文的来源仍保留网址和原因；上传文件先完整保存再解析。
5. 从实际原文摘录“证据片段”，选择性质，添加已知位置。逐字原话必须在指定来源版本中实际存在。
6. 将资料关联选题，在脚本段落选入具体证据。输入自动保存，失败和并发冲突会显示；未保存时离开有提示。
7. 保存版本快照，再点“带来源导出”。Markdown与JSON包含正文、镜头、具体证据、原始链接、位置、来源版本、权限/署名要求及待核实项。

## 当前能做

- 批量网址/分享文案、文字和原话、图片/影音/文档真实保存；持久队列、限次重试、取消和逐项结果。
- 来源与不可变版本、原文件SHA-256、具体证据；多选题复用与手工同源分组，不重复保存文件字节。
- 内容类型、主题/标签、工作状态与使用权限分别保存；全文与组合筛选。三字以上使用FTS5，短词回退LIKE；列表最多显示1000条，可用检索缩小范围。
- DOCX段落、XLSX单元格原值、PDF文字层、文本读取；图片和影音保存原件，部分媒体参数从文件实际读取。
- 手动分段脚本、镜头、引用、自动保存、并发冲突保护、命名快照、历史比较/恢复、带来源导出。
- 最小人工发布登记，实际作品引用固定脚本版本；不调用任何发布平台。
- 一致数据库快照、原文件和SHA-256清单的完整备份；恢复验证到文件字节、数据库结构及外键关系。

## 当前网页采集书签

资料库顶部“采集当前网页”提供书签脚本。将“采集到内容工作台”拖到书签栏，在目标页主动选中文字，再点书签，会打开本机工作台的待保存预览。只读取所选文字、当前标题和网址，不读取Cookie或登录凭据。选择为空时需补原文。

部分浏览器或网页CSP可能阻止书签；此时复制原文和网址手动保存。桌面Chrome书签安装/运行尚未完成实机验收（本机自动化连接受限）；当前网页片段保存接口有测试，不能把它等同于全站点浏览器兼容验证。手机与Safari实机也未验。

## 数据位置与重启

Mac默认位置：`~/Library/Application Support/Content Workbench/data/`。`workbench.sqlite`保存元数据、版本、证据和关系，`blobs/`保存完整原件。数据不会依赖浏览器缓存，不会自动上传GitHub。请勿删除此目录。

关闭终端中的服务（Ctrl+C），重新执行`npm start`，页面重载后仍可找到资料。工作进程随服务启动；任务保存在SQLite，正常退出后在下次启动继续，过期租约重新排队。实际睡眠、关机和断网会阻断执行。未启用定时热点或外部推送。

## 备份与恢复

“账号与备份 → 生成完整备份”，完成后下载 `.tar.gz`。备份包含数据库、全部已保存原件与校验清单，不含程序依赖、旧备份或服务CSRF会话。

重新上传完整备份，会先校验每个文件的大小/哈希、数据库结构及关联。点“确认恢复到新目录”只创建独立副本，不覆盖当前工作空间；页面显示新目录。停止服务后可运行：

```sh
node server/main.mjs --data /新的恢复目录 --port 4781
```

也可用命令恢复到**不存在的新目录**：

```sh
npm run restore -- /完整备份.tar.gz --data /新的数据目录 --confirm
```

恢复副本中的未完成任务会取消，需检查后人工重试，以免恢复即发起外部读取。

## 明确边界

- 单文件最大1GB，每次网页采集最多30网址；文件界面逐个上传，每批最多30个。备份上传最多2GB压缩/20GB展开。
- 文档解析最大12MB，PDF最多50页，Excel最多10表/每表2000行，索引文字最多50万字；超限时完整原件仍在，状态为部分完成。Word不推算排版页码，Excel不计算公式。
- 旧DOC/XLS及未知格式只保存原件；扫描件OCR、影音内容识别、语音转写未接入。
- 网页采集只读取合法可访问的公开内容，不绕过登录、验证码或付费墙；原件是收到的响应文件，正文提取还需人工核验。
- RSS手动保存的是订阅原文，不是自动热榜、趋势判断或每日简报。抖音主页短链不提供后台权限，未取得的视频和字幕不会出现虚构拆解。
- 模型、外部通知和抖音API关闭；没有费用调用、消息投递或平台发布。
- 目前只提供单人本机访问，没有公网认证/多人隔离，不可直接对外绑定服务。
- Node内置SQLite在此版本是Release Candidate，已锁定Node24并通过本地验证，CI以实际工作流结果为准；其他环境需按结果分别核验。
