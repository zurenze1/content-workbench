# 祖仁泽自媒体工作台 · 0.8.0

在本机管理选题、素材与证据、脚本版本、审稿交付、发布记录和数据复盘。支持单人管理多个 IP，数据保存在自己的电脑。

**[下载完整源码包](https://github.com/zurenze1/content-workbench/releases/latest)** · [工具箱](https://github.com/zurenze1/screenshot-translate-video-downloader) · [人生档案](https://github.com/zurenze1/life-archive)

## 开始使用

需要 Node.js **24.21.0（24.x）** 和 npm。下载并解压源码包后，在该目录运行：

```sh
npm ci --ignore-scripts
npm run build
npm start
```

打开 **http://127.0.0.1:4781/**。Mac 可双击 `启动工作台.command`，脚本检查环境、安装依赖、构建并启动服务；保留终端运行，按 Ctrl+C 停止。本次提供源码包，需要上述运行环境。

服务默认仅监听本机。首次启动是空数据库，不带作者账号、作品、文稿、录音、附件、备份或模型密钥。其他电脑的 Node 安装、浏览器兼容和语音识别环境仍需各自配置。

## 能做什么

- 账号与 IP：分别记录定位、受众、节奏和服务范围，按当前 IP 查看项目与复盘；历史未归属项目可单独查看。
- 选题与素材：RSS 热点、公开网址与文件采集、持久队列、来源版本、原件哈希和证据摘录；无法读取的资料保留失败原因。
- 逐句分镜：左侧起止时间、中间文案、右侧图片/视频/资料；支持文件上传、图片粘贴、资料库选择与链接出处，固定素材版本并自动保存。
- 深空蓝界面：紧凑仪表盘、真实项目分布、常用创作入口，支持明亮阅读。
- 脚本与制作：六阶段看板、段落编辑、证据引用、口播时间预算、版本快照、平台版本与制作进度。
- 审稿与交付：审核绑定具体版本；改稿后重新确认；导出 Markdown、JSON 和带引用原件的交付 ZIP。
- 发布与复盘：区分计划和实际发布，记录真实使用的版本；导入 CSV/JSON 指标、比较兼容样本、形成待验证实验。
- 备份与恢复：数据库与原件完整备份，恢复前验证摘要和关系；密钥独立保存在本机，不进入备份。

模型默认关闭，可配置本机 Codex 或自己的 Anthropic 凭据；本机转写和 FFmpeg 需要另行配置。没有自动对外发布、自动发消息或抖音官方后台接口。测试中的合成数据不代表平台真实接入。

## 本机数据

Mac 默认目录为 `~/Library/Application Support/Content Workbench/data/`。`workbench.sqlite` 保存关系和版本，`blobs/` 保存原件。完整源码与 Release 不含这些数据；更新源码不会把旧资料打包公开。

## 验证

```sh
npm run build
npm run check
npm test
npm run release:check
```

自动测试使用独立临时目录和合成素材。本次结果见 [公开版验证记录](docs/PUBLIC-RELEASE.md)。保留的较早验收文档描述当时版本与本机范围，不代表在其他电脑或所有平台上通过。

代码当前未授予开源再分发许可（`package.json` 标记 `UNLICENSED`）；第三方依赖遵循各自许可证。公开可查看、下载，不据此宣称全部代码采用 MIT。个人安装数据不会随源码进入 GitHub。

## 可选字体

界面优先使用本机提供的新青年字体。字体文件不随源码或 Release 分发；可自行取得适用授权后，把字体保存为数据目录中的 `ui-font.otf`。没有该文件时使用本机可用字体，软件照常运行。字体是界面配置，不纳入资料备份；备份恢复后需重新放置字体。

文悦新青年体的官方说明见 https://wenyue.cn/fonts/506 ，商业使用需购买授权；本项目未提供或转授字体授权。
