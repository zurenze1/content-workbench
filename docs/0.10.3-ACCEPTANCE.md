# 0.10.3：本机分镜执行台

分镜执行台从外链入口升级为本机编辑工作区。用户确认使用已有工作台；复用选题、脚本草稿、不可变版本、素材原件和备份，不引入新依赖或数据库表。

## 使用范围

- 选择当前IP项目或新建项目，粘贴 / 读取TXT、Markdown并按句建立镜头；默认追加，替换前留版本。
- 逐镜编辑时间、口播、画面、花字、转场、音乐音效和执行状态；可调整顺序、添加、移除、筛选。
- 素材分镜共用同一份脚本，支持原件上传、素材库关联、主选 / 备选 / 参考、图片预览、视频播放和原件下载。
- 草稿自动保存与手动保存，错误时间阻止提交，多窗口冲突拒绝覆盖。上传未完成或修改尚未保存时阻止离开；失败可下载当前草稿。
- 保存固定版本；移除、替换和恢复前留版本。旧版可查看、下载或继续编辑。
- CSV、Markdown、JSON导出取固定版本。CSV含起止、口播、画面、花字、转场、声音、状态和素材出处，带UTF-8 BOM并防护电子表格公式单元格。

## 验证方法与边界

- 自动检查覆盖旧稿兼容、字段校验、固定版本不被后改覆盖、CSV引号 / 换行 / 空时间 / 零起点、真实HTTP下载、失效revision、服务重启及完整备份恢复。
- 独立测试库的浏览器实际完成新建、脚本导入、填写保存、上传图片和视频、刷新重读、错误时间拦截、移除前版本、恢复旧版、CSV下载及内容核对。
- 上传图片实际解码，原视频经控件开始播放，currentTime增加且媒体无错误；素材原件字节和引用关系另经自动检查。
- 390px、320px浏览器窄屏检查：整页未横向溢出，执行表在容器内左右浏览，筛选与版本弹窗可操作。未做实体手机测试。
- 正式数据在升级前独立备份，切换后逐表比较。QA数据只留独立测试库；公开源码和源包不含数据库、原件、私人工具地址、商业字体、凭据或验收截图。

原在线地址仍由本机配置提供，保留为参考入口。本版未修改原在线网站，也未接入自动剪辑、MP4合成或平台发布。发布包沿用Node24源码ZIP，非独立Mac安装程序。

本次结果：公开副本105项自动测试全部通过，55个服务 / 脚本 / 测试文件语法检查通过，生产构建通过，130个源码文件发布检查通过。正式服务已切换至0.10.3，53张表逐行摘要与升级前一致，完整性检查ok，外键错误0；正式浏览器可打开原有项目的执行表。
