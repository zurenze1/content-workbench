# 0.9 工作流精简、说明书与分镜提案

日期：2026-10-26。沿用现有服务与数据库，新增字段保存在原脚本JSON中，无新数据库或破坏性迁移。

## 已实施

- 日常导航归为今日、发现、项目创作、素材库、我的作品、发布复盘六区；管理工具转入设置，说明书始终可进入。
- 删除旧六阶段拖动看板、独立热点收件箱、全部功能目录、跨项目平台矩阵及闲置旧首页组件。手动热点录入、平台规则设置移入对应工作流，原数据/API不因取消页面而删除。
- 项目内保留素材证据、脚本镜头、审稿交付、发布登记，加入项目助手。当前项目对话优先，其他历史对话保留只读，避免带着另一个项目的对话继续发送。
- 统一搜索已整理资料与归集原件；本页相同哈希不重复列出，原件可转成资料并关联项目。
- 分镜素材增加主选/备选/参考和剪辑说明。每句最多一个主选；旧引用不擅自补角色。提案展示已有文案、画面、出处和权限，支持总览、切句、全屏和键盘；未知时间与缺素材明确待补。
- 草稿、固定快照、历史提案、来源导出、交付包及备份恢复沿用既有链路。上游copy-shot-proposal仅作交互研究，未复制代码或案例图片。
- 模型启用开关不再显示为调用成功；说明书中的本机检查只读状态与接口，真实模型生成另行测试。

## 验证范围

- 本机完整自动测试92项通过，TypeScript及生产构建通过，服务/脚本/测试语法检查通过。
- 新测试覆盖角色/说明保存、多个主选与错误类型拒绝、旧引用兼容、快照不可变、带来源导出；原件备份恢复测试同时核对新增字段与原件字节。
- 正式服务实际重启到0.9.0；11类核心业务表逐行与升级前数据库快照相同，SQLite完整性通过、外键错误0。生产库没有混入验收数据，未删除或改写原件。
- 隔离浏览器实测：修改说明和主选→保存→重载→快照→历史提案→恢复为当前草稿→隔离服务重启，草稿与快照一致；新版快照仍保留改稿，旧版恢复不改历史。
- 统一搜索实测：按原文命中归集文稿、预览、转为资料并关联项目；已整理图片与同哈希原件不重复列出。
- 项目内平台规则仍可进入；从固定脚本建立平台初稿并保存。不是实际平台发布。
- 提案视频实际播放到0.238秒，随后到1秒结束，duration=1，媒体错误为空；未知时间/空素材、前后句、全屏左右键和Esc已检查。发现最后一句导致焦点丢失后，修正全屏键盘监听并复测。
- 说明书六项只读检查完成；本机既有Codex登录在隔离项目完成一次实际生成。没有发送生产项目资料，也不据此承诺每次请求或其他账户成功。

- 平台链接下载、登录/验证码、素材使用许可、实际剪辑、平台发布和后台原表导出仍依赖本人及平台条件。未重新验证所有平台链接或转写准确率。
- 完整新增字段恢复使用隔离原件库；本轮没有重复做生产全量原件库恢复。数据库快照和源码备份保留，不能把记录不变表述为本轮重新哈希校验全部生产原件。
- CSS视口检查不是手机实机；原生Mac包装窗口和最终审美本轮未全面代验。
- 公开源包只同步程序、版本和说明，不含个人数据库、原件、备份、模型凭据、字体或验收截图。公开副本检查及CI结果以对应提交和Release为准。
