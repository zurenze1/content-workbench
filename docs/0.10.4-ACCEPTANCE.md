# 0.10.4：分镜执行台云白与天蓝主题

分镜执行台采用天空与白云的配色：页头可显示本人提供的背景，执行表与输入框保持清楚的白底，导航、按钮、状态和边框采用蓝色。仅在分镜执行台应用此主题，其他工作区沿用原外观。

## 本机素材与公开源码

- 可选背景是数据目录中的固定文件 `ui-execution-background.jpg`，通过本机只读接口 `/api/execution-background` 提供；前端由 bootstrap 标记决定是否加载。
- 缺少背景时显示天空渐变，不渲染失效图片；不接受任意文件路径或远程地址。
- 原图保留。本机背景、商业字体、个人数据、备份和验收截图均不进入公开仓库与源码包。发布检查增加背景文件排除。
- 本次没有新增依赖、改动表结构、脚本内容或自动化设置。

## 已执行验证

- 本机与公开副本生产构建通过，55个服务、脚本和测试文件语法检查通过。
- 全套105项测试中104项首次通过，1项执行台HTTP测试遇隔离服务启动超时；该项独立重跑通过，未放宽断言或修改超时。
- 隔离HTTP检查覆盖：无背景404及标记false；配置后标记true、JPEG类型正确、响应字节与原图一致。
- 浏览器检查页头实图、执行表、素材视图、新建弹窗及主题退出范围。390与320宽度下整页无横向溢出，执行表容器内实际键盘横向滚动有效；尚未做实体手机测试。
