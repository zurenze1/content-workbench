# 0.3 创作花园、Codex 与视频迁移

日期：2026-10-15。状态：本机升级，未公开部署或上传个人视频。

## 可用入口

正式服务仍为 `http://127.0.0.1:4781/`。桌面原有启动图标继续使用同一项目与数据库。

- 创作花园：深色花卉主题、可收起的主视觉、真实数量、最近作品直接播放。
- 视频作品库：扫描、勾选、持久导入任务、取消、内容哈希去重、海报、媒体参数、分类、搜索、收藏、笔记、原件下载、关联项目和来源入口。
- 创作助手：Codex / 当前 ChatGPT 登录、连续对话、本机持久记录、停止、失败重试、复制、主动保存回复到资料库。发送时明确选择项目文字或视频名称与参数；未实现视频画面理解或自动转写。
- 脚本 AI 辅助：三种开头、证据缺口、提纲，沿用已有引用校验，建议不自动改写正文。保留原 Anthropic 接入。
- 既有热点、选题看板、资料、参考拆解、脚本版本、日历、指标导入、复盘、备份与恢复保留。

## 模型实现与网络处理

使用本机官方 Codex CLI 的原生登录，不读取或复制 OAuth 凭据。模型目录通过 app-server 的 model/list 获取，调用通过 ephemeral codex exec；关闭用户 MCP 配置、shell 与多代理工具，以只读模式运行。聊天记录、导入任务与视频索引存服务端 SQLite；原件和海报进入哈希文件库，因此完整备份包含新增数据，凭据不进入备份。

本机 WebSocket 路由发生证书名称不匹配，HTTPS 通道正常。工作台单次调用使用 Codex 支持的 HTTPS/SSE provider 配置，保留 TLS 校验，不修改用户全局配置。修正将重连过程提示错误误当最终失败的问题；只有最终完成的调用才记录成功。相关依据：[Codex 非交互模式](https://developers.openai.com/codex/noninteractive)、[配置参考](https://developers.openai.com/codex/config-reference)、[app-server](https://developers.openai.com/codex/app-server)。

## 主视觉

用户提供的《创意作品集》用于留白、大字与图文关系参考，《盛开》为必须保留的女生形象。原 WebP 为轮播动画，首页改用稳定画面。通过内置 image_gen 清理截图中的导航、卡片、文字和指针，尽量保留原女生与花卉构图，生成版保存在 public/studio/bloom-clean-v1.png，实际页面使用同版 JPEG。原图及首次静态解码保留。

清理提示词：以原图为编辑目标，保持同一位女生的脸、闭眼表情、虹彩材质、粉色牡丹和金属花丝；仅移除网页UI、字、鼠标和紫色箭头，补齐相邻深色花卉背景，不添加文字或标记。审美仍以祖老大实际观看为准。

## 当前边界

仅监听本机。抖音后台接口、外部推送、自动发布、OCR和视频转写未接入，界面按真实状态显示。扫描采用限定的创作目录，无法访问的文件逐项显示。导入保留原文件，不把已导出、已迁移等同于已采用、已发布或素材权利已确认。无后台24小时在线或手机远程访问承诺。
