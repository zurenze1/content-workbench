## 边界

- 内置浏览器读取抖音DOM超时、Chrome扩展接口失败；改用用户正常Chrome可见界面可采集。本轮没有接通官方video.comment接口，也没有伪造签名、导出登录会话或使用付费解析服务。
- 工作台“读取公开评论”按钮读取页面公开JSON-LD；受限站点会显示部分完成。每日跨博主采集由已有Codex任务使用正常浏览器完成。即时全量抖音抓取未实现。
- 公开音视频直链和页面公开媒体可尝试解析，受登录、验证码或下载保护的链接会保留出处并要求用户提供原件。没有承诺任意抖音链接都能下载。原视频语音转写已实测；平台链接自动转写的覆盖范围仍需逐站验证。
- 模型判断、原文、评论观点与已核验事实分开；机器ASR不保证所有人名/数字正确，没有可靠时码则不导出伪SRT。
- 桌面入口指向原有应用启动器和新代码；macOS本机运行。手机硬件、其他电脑安装与公网多人访问未测试。
