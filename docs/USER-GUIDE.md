# 自媒体工作台使用说明 · 0.9

打开工作台后，侧栏“使用说明”提供相同步骤和可点击入口。本地地址默认 http://127.0.0.1:4781/#page=guide 。

## 六个工作区

| 入口 | 什么时候用 |
| --- | --- |
| 今日工作 | 看待办、正在制作和待补复盘；继续原项目 |
| 发现 | 看人物文化线索、博主评论、公开活动与AI工具；判断适合哪个IP、转成选题 |
| 项目创作 | 一个项目内完成素材、证据、脚本、分镜提案、审稿、平台版本和发布登记 |
| 素材库 | 一次检索已整理资料与归集原件；查视频、图片、音频、文稿及逐字稿 |
| 我的作品 | 完整成片按作品和版本收组，样片与试听在“制作过程” |
| 发布复盘 | 记录发布计划、导入真实后台数据、复盘和提出下一实验 |

设置与管理包含账号/IP、模型、备份恢复、任务、RSS、原始档案和回收站。低频设置不再占日常导航。

## 做完第一条内容

1. **建立项目**：从“发现→选题判断”转入，或“项目创作→新建项目”。选账号/IP，写清核心问题、受众和角度。没有依据时不要给历史项目猜归属。
2. **准备资料**：右上“采集资料”可粘贴文字、链接或上传文件。“素材库→搜索全部素材”同时查原文和已归集原件，点原件可存成可引用资料并关联项目。同内容哈希不在同页重复列出；原件总量与已整理资料量不可直接相加。
3. **核对与摘录**：资料详情保留原文、来源版本与权限。在原文中摘录具体证据，区分原话、事实、评价和推断。保存链接不等于取得原片；公开可看不等于允许使用。
4. **转文字**：在“音视频逐字稿”上传本地音视频或导入现有字幕。本机转写仍需校对姓名、数字、口语和断句；无时间戳时不伪造时间。平台链接失败可回到自己有权使用的本地原片。
5. **写分镜**：项目→脚本与镜头。左侧填写已知起止时间，未知留空；中间写逐句文案、画面需求和剪辑说明；右侧放素材。新添加的首份素材默认主选，其余备选，可手动调整；每句只允许一个主选，切换时旧主选转为备选。旧引用未指定用途时保持未指定。
6. **看提案**：切到“提案演示”检查文案与A主选/B备选，保留原比例，查看出处与权限。可切文案总览、全屏、前后句；全屏可用左右方向键与Esc。没有原件或预览失败会明确显示，不用占位图冒充。
7. **保存版本**：编辑自动保存，看到“已保存到本地服务”再离开。保存版本快照固定正文、时间、剪辑说明、素材角色与来源版本。历史版本可查看、导出或恢复为当前草稿，后续改动不覆盖历史。
8. **审稿交付**：保存快照后，在“审稿交付”提交具体版本，记录已经发生的真实意见。可生成标明状态的交付包；超过原件打包预算的项会写明另交。
9. **平台与发布**：项目→发布登记，可设置平台规则、从固定脚本生成平台版本，再人工修改。实际发布由本人在平台完成，回来登记真实链接、时间与采用版本。历史版本未知应标记待确认，不拿当前草稿冒充当时版本。
10. **复盘**：抖音后台Excel由本人导出，在“发布复盘→抖音后台数据”预览，确认作品、账号、单位与采集时间再入库。其他数据支持CSV/JSON、截图候选或手工录入。缺失不是0，单条数据不能证明因果或最佳发布时间。

## 创作助手

入口在项目内“05 项目助手”，默认带入当前项目文字和证据。视频只发送名称与参数，不代表模型读过视频画面。助手回复不会直接覆盖稿件，可核对后复制或存为资料。旧对话保留；对话本身可能属于其他项目，发送前核对历史与当前上下文。

需要设置中的模型连接和可用额度。顶部“模型·已启用”只表示启用状态；说明书里的检查可核对登录与模型列表，不能代替一次真实生成。未连接时手动创作仍可使用。

## 可用条件与失败处理

- **本机可操作**：项目、资料、证据、分镜、提案、快照、审稿记录、手动数据导入和备份。源码不包含个人资料。
- **依赖本机环境**：转写、FFmpeg、Codex登录与模型额度。其他电脑需要各自配置，不能套用作者电脑的验证结果。
- **依赖平台条件**：链接有效性、登录、访问和下载规则。失败保留出处和原因，到“设置与管理→采集任务”检查，不补造内容。
- **人工完成**：登录/验证码、使用权确认、剪辑、实际平台发布、后台原表导出。没有自动发消息或自动发布承诺。
- **RSS与早报**：RSS需配置来源，本机服务运行时才能按频率抓取；已有Codex早报是外部任务入库，两条链不同。睡眠、断网、关机仍会中断执行。
- **保存冲突**：先保留正在编辑的文字，刷新核对其他窗口，不反复覆盖。误移素材可到回收站恢复。
- **备份恢复**：完整备份含数据库与原件；先验证到字节与关系，再恢复到独立目录。密钥与本机界面字体不进入资料备份。

## 更新后入口变化

旧六阶段看板并入制作进度；独立审稿列表并入项目待审筛选；跨项目平台矩阵并入项目发布登记；全局助手移到项目；旧热点收件箱并入选题判断。旧链接转到相应工作区，原数据和引用保留。

本说明是操作方法，不代表所有平台链接、每次模型请求或每台设备均已通过验证。


## 0.9.1：点击数字查看真实记录

- 今日工作中的进行中、待审稿、待复盘、阶段与全部选题，可打开对应项目清单；资料数量进入资料库，原件数量打开全库分页检索。全库选题含待归属历史项目，当前IP统计与全库统计分别标明。
- 作品复盘→选择作品→点击任一指标名称、原始值或标准值：查看原始列名、精确标准值、换算单位、平台定义、采集时间、统计口径及原始导入文件。后台快照不会因打开页面自动更新。
- 设置与管理→模型与连接→发送连接测试：只发送固定测试语句，使用已保存模型配置，不带项目、视频和历史对话。真实回复、任务失败、取消及采集时间如实保存，测试计入一次调用。更换模型后先保存。
- 账号与IP可保存本人公开主页和定位，并点击打开主页；这里的资料关联不等于平台OAuth授权。人物故事与品牌解说等方向按本人实际定位填写，不用模型推断账号归属。
- 抖音后台仍通过本人导出的Excel预览、确认后导入；公开作品与评论通过正常登录的网页读取，保留真实出处与样本范围。公开数据不混入创作者后台指标，逐字稿需先取得可用音视频再转写核对。
