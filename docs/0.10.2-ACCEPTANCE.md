# 0.10.2：独立分镜执行台入口

用户需要将现有在线分镜工具作为工作台中的独立板块使用。新增第七个导航板块和首页独立入口卡片，共用同一工具组件；支持键盘访问和窄屏排版。

- 只打开原工具，不复制或修改原站的脚本、素材与登录数据。
- HTTP/HTTPS链接使用新标签页、noopener与noreferrer；非法或未配置地址不生成可点击入口。
- 私人工具地址保存在本机配置，公开源码与源包不包含作者的实际地址。
- 复用现有服务、设置存储和页面布局，无新依赖、数据库迁移或个人内容改写。

验证结果见此版本提交、CI与Release说明；生产浏览器点击结果另保留于本机任务证据。夜间主题、第三方站点全部编辑能力和跨设备登录不在本次入口接入的验证范围。

本机和干净公开副本均通过：生产构建、54个服务/脚本/测试文件语法检查、102项自动测试。公开副本发布检查128个源码文件通过。生产浏览器已实点首页“进入板块”与“打开分镜”，成功进入原在线分镜的执行表。正式库53张表逐行摘要保持一致，唯一预期新增为本机工具链接设置；完整性和外键检查通过。没有进行手机实机测试。
