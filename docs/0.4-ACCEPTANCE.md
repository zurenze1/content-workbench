# 0.4 一稿多发与后台截图识别

日期：2026-10-16。数据库结构 v3（只新增 variants、data_screenshots 两张表；备份恢复接受 v1—v3）。

## 一稿多发
- 选题页“一稿多发”：为抖音、视频号、小红书、公众号、B站、快手等生成平台版本，各自有账号、标题、文案、标签、封面说明、状态、排期和发布记录。
- 初稿按脚本版本自动拼接：图文带“资料来源/署名要求”，长文章带小标题与参考资料，视频只取首句作描述。只重排原有正文和出处，不新增事实。
- 字数上限默认留空，由你按平台后台实际规则在“一稿多发 → 平台设置”填写；留空不检查。
- 排期写入发布日历并显示平台；登记发布后固定当时的标题、文案、标签与脚本版本（数据库触发器保护），改稿需“复制为新版本”。
- 数据复盘按平台分开：快照记录平台，不同平台、不同账号不进同一参考组；发布时段可按平台筛选。
- 左侧新增“一稿多发”总览：选题 × 平台状态矩阵。

## 后台截图 + 本机文字识别
- 作品复盘页“后台截图录入”：上传、拖入或 ⌘V 粘贴，PNG/JPG/WebP，每条作品最多8张、每张≤8MB，原图按哈希保存并进入完整备份。
- 识别在本机任务进程中完成：tesseract.js 7.0.0（Apache-2.0）+ chi_sim 4.0.0_best_int 语言包（MIT），首次使用时复制到数据目录，不联网下载、不上传截图。自行实现，没有复制积木工作台（jimu-workbench，仓库无许可证）的代码。
- 识别结果只是候选值：同一行、下一行、上一行按位置配对；数值冲突不自动选择；“万/千”标为近似值；未见百分号、计数为负都提示。勾选并填写采集时间后才写入数据快照，截图记为依据。
- 已知限制：只认识指标目录里的名称和别名；复杂多列、压缩、小字截图可能识别不准；中英双语同时加载在 tesseract.js 7 中报错，因此只加载中文模型（数字、%、2s 可识别）。
