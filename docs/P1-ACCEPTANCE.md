# P1真实验收记录

日期：2026-10-14。版本0.1.0。范围为MAT-01—05、TOP-01基础、SCR-01/02基础，以及A01—A05、A12、A20—A24适用部分。完整PRD的P2—P5尚未完成。

## 自动检查

- `npm ci --ignore-scripts`：依赖安装；锁定版本，不使用其他项目的node_modules。
- `npm run build`：TypeScript检查及Vite生产构建。
- `npm run check`：服务、脚本、测试文件语法检查。
- `npm test`：18项测试，含真实HTTP服务器/任务进程的端到端测试。具体最新命令结果以GitHub工作流与本机日志为准。
- `npm run release:check`：源码发布边界检查，不包含数据库、原件、备份、私有数据和凭据。

## 实际接口与持久化

- 独立HTTP服务中创建账号、选题、手动原文、具体证据和脚本快照。发布记录采用隔离测试链接，仅验证版本引用，不代表平台发布成功。
- 实际通过multipart上传合成PNG、1秒MP4和PDF；下载字节与输入完全相同。视频Range返回206和指定32字节；PDF文字及第1页位置真实提取。
- 同文件重复上传去重；一份资料关联两个选题，移除其中一个关联后其他关联和原件存在；同源分组不重复显示为独立出处。
- 停止并重启完整服务，重载资料与脚本；旧快照不受后来改稿影响。完整备份恢复到新目录，再启动独立HTTP服务核对引用、发布版本与原件。
- 任务租约恢复用过期租约夹具模拟故障，随后启动真实worker验证重新执行；未把它记为外部抓取中断实测。
- 故障与安全：不在原文中的引语拒绝；过期草稿修订号拒绝覆盖；私网/回环与非标准采集端口阻止；跨站读取和缺少CSRF的写入拒绝；网页脚本未执行；截断或超限上传不留下登记残片；原件字节损坏拒绝生成备份。

## 浏览器与真实公共来源

- Codex内置桌面浏览器真实操作：手动提交联合国中文RSS，原始XML响应与5997字可读内容保存成功，30条订阅条目。此结果仅是公开RSS采集，不是抖音热榜或定时简报。
- 实际创建隔离选题、关联RSS、摘录具体原文、保存证据，再写脚本/镜头并选入引用。自动保存、来源版本和脚本快照在服务重启及页面重载后仍在。
- 浏览器实际下载带来源Markdown；文件包含出处、具体证据位置、不可变版本、权限和未解决问题，不只是正文。
- 实际文件选择器选入合成PNG与MP4，逐项保存原件并返回SHA-256。
- 浏览器生成完整备份、下载、重新上传验证、明确确认恢复到新的目录。XML/PNG/MP4原件逐文件哈希和字节数与原库一致，选题/证据/脚本/关联数量一致，外键错误为0。
- 恢复副本以另一个端口启动，浏览器独立读取成功。验收数据与默认工作空间分开，不上传GitHub。

## 接入与未完成项

- 模型、外部推送、抖音API、OCR、语音转写、定时热点均未配置/未接入；没有将连接状态伪装为成功。
- 上传媒体与文档、手动资料、公开RSS采集已实际验证。当前网页片段保存接口可用，书签入口已提供；Chrome自动化连接失败，真实Chrome书签安装/点击、Safari和手机实机仍未验证。
- 来源元信息与同源关系需人工核验；脚本重要说法不自动判真。旧Office格式、扫描件、受限视频只保存原件/出处或待补状态。
- A23用“无内置演示库、独立测试数据目录”实现隔离；没有提供删除演示数据的动作，也没有操作用户真实记录。
- A24浏览器已检查的是桌面内置浏览器及390px尺寸模拟，不等于手机实机。留存、后台指标导入、热点生命周期与最终成片对齐属于后续阶段。
- 依赖Node24，默认仅监听127.0.0.1；未实现公网身份认证，不部署公网。
